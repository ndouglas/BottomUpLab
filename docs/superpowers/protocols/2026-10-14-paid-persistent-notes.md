# Paid persistent notes — declarative protocol 1

This is a prospective working registration, derived from the approved 2026-10-14 design and implementation plan at base `10813005f63fab0a495eedd9efd5e1eda25f3a86`. It authorizes no production collection. Stage 1 remains In Progress until independent protocol review, source-blind author and numerical reviewer approvals, full trace equality and fixture sealing. Later implementation must implement this protocol or obtain a reviewed amendment before collection. ReadNote is included in Primitive: its omission from the plan's illustrative enum is a controller-confirmed typo, since the approved design requires it.

## Exact wire language

Every object below has exactly the listed fields; all are required. Unknown fields, duplicate object keys at any nesting depth, absent fields, floats, booleans used as integers, overflowing integers, invalid UTF-8, trailing data and noncanonical ratios are rejected before mutation. Nullable fields serialize explicit `null`, never disappear. Arrays have the indicated order/length; no maps keyed by participant IDs occur. U is an integer 0..2^64−1; I is −2^63..2^63−1; B is a JSON Boolean. Operational errors are separate results, never substituted Episode rows.

Canonical encoding is UTF-8 JSON with recursively lexicographically sorted object keys, preserved array order, compact separators, no whitespace or final newline, ASCII escaping disabled, standard short escapes for controls and quote/backslash; all supported strings are ASCII. Integer tokens have no leading zero or plus sign. Ratio is `{numerator:I,denominator:U}` with positive denominator, gcd=1 and zero exactly 0/1. JSON input may have whitespace/order variations; canonical output and all digests use these rules. A parser must detect duplicate keys before constructing maps. Validate length/shape before allocating complete buffers. All digests are lowercase 64-character SHA-256 strings.

Role is Writer/Reader (indices 0/1); Cell P/O/C; Good Left/Right; Note Blank/NoteLeft/NoteRight; Arm Retained/Erased/NoNote/NoAcquireNoNote; WriterProgram ObserveWrite/ObserveSilent/Silent; ReaderRoutine BlindGuess/InspectFirst/ReadAdaptive/Oracle; BlankChoice Inspect/GuessLeft. Enum wire strings are precisely these spellings. Phase Writer/Departure/Reader/Terminal; TerminalReason Delivered/Deadline; EventKind Action/Departure/Settlement; ActionStatus Applied/Blocked. BlockReason WrongLocation/NoKey/NoRecipient/CargoOccupied/NoCargo. Writer after departure, wrong role/phase, extra opportunities and any action after terminal are invalid histories, not paid blocks.

IDs are nonempty distinct ASCII strings, at most 32 bytes, matching `[A-Za-z0-9_-]+`; default Agent-A/Agent-B. They are opaque display labels, never decision inputs, sorted keys, event ordering or semantics. Normalize all identity-comparison/census/reference payloads to Agent-A/Agent-B by role, preserving original labels in selected exports. Registered census uses default IDs. No semantic inference from labels is permitted.

Stratum = `{acquisition_cost:U,write_cost:U,note_read_cost:U,manifest_inspection_cost:U,writer_share:U}`. Registered values are s=(1,4), w=(1,2,4,6), r=(1,2), i=(2,4,8), b=(0,3,6). Config = `{stratum:Stratum,arm:Arm,routine:ReaderRoutine,request:Good,ids:Ids}`; Ids = `{writer:string,reader:string}`. Public selected Config parsing requires grid membership. Off-grid ties and malformed histories use private engineering witnesses, never collector keys. Reader share g=12−b. PublicSettings = `{acquisition_cost:U,write_cost:U,note_read_cost:U,manifest_inspection_cost:U,own_share:U,initial_credits:U,writer_opportunities:U,reader_opportunities:U,correct_total_reward:U,request_prior:[Ratio,Ratio]}`. Constants 32,4,6,12 and [1/2,1/2]. No arm or peer share is embedded.

Primitive = `{kind:string,cell:Cell|null,note:Note|null,good:Good|null}`. kind is Wait/Move/InspectManifest/PassKey/WriteNote/ReadNote/Pickup/Deliver; exactly Move uses cell, WriteNote uses nonblank note, Pickup uses good; other payloads null. P is a real cell; movements only P↔O and O↔C, at cost one, with O↔C requiring own key. P↔O is unblocked by keys and unused by census. Nonadjacent Move is InvalidInput. Move to current cell is InvalidInput. WriteNote(Blank) is InvalidInput; resetting uses the researcher-only ResetField witness operation, not a participant primitive.

## State, views and events

Clock = `{boundary:U,phase:Phase,writer_slot:U,reader_slot:U}`; slots count committed actions, not attempted operational errors. Initial boundary0 Writer slots0/0. Writer action k produces boundary k, Writer slot k, reader0; departure produces boundary5 Departure slots4/0; Reader action j produces boundary5+j Reader slots4/j. Final marker boundary6+j Terminal slots4/j, j≤6. Initial +4 actions +departure +up to6 Reader actions +marker ≤13 captures. Deliver settlement occurs atomically in the action; final marker records already settled state, never settles twice. Deadline occurs after sixth committed Reader action if not delivered; its marker pays zero and retains spending/cargo/custody.

PublicStatus = `{writer_active:B,reader_active:B,terminal:B,terminal_reason:TerminalReason|null}`. Writer active until departure; Reader remains active as cohort participant, but cannot act in terminal. Terminal reason is null before a terminal transition; successful Deliver sets Delivered atomically in its action, while deadline becomes Deadline in its final marker; departed Writer never regains activity.

Participant = `{role:Role,cell:Cell|null,active:B,key:B,cargo:Good|null,credits:U,spent:U,reward:U}`. Writer cell becomes null at departure; inactive key ownership remains possible. Reader starts O, Writer C. Credits+spent=32. Cargo empty initially. Physical = `{request:Good,field:Note,key_owner:Role,participants:[Participant,Participant],goods:[B,B],lineage:Lineage|null,settled:B}`. goods index Left/Right are available cache stocks, initially true/true, consumed on successful pickup; key_owner always exactly one role, even inactive. Participant key booleans agree with key_owner. Lineage = `{writer:Role,observed_request:Good,observation_clock:Clock,write_clock:Clock,symbol:Note}`; field overwrite replaces lineage; erasure/reset sets field Blank and lineage null. Successful raw false-note witnesses preserve true observed_request and differing symbol, never imply registered truthful behavior.

LocalMap = `{sensed_at:Clock,cells:[MapCell]}`. MapCell = `{cell:Cell,sensed_at:Clock,occupants:[Role],key_holder:Role|null,goods:[Good]}`. At most three cells, ordered P,O,C, retaining most recent own sensing at each visited cell. Initial and each committed own action except ReadNote (Applied or Blocked, including Wait) sense only actor's current cell after mutation, replacing that cell entry. LocalMap.sensed_at is last actual own sensing clock. Occupants are active agents in that cell, ordered Writer/Reader; key_holder is present active carrier or null; goods are visible available labeled cache stocks at C, else empty. Board presence is public topology; map NEVER includes field, lineage or manifest request. No neighboring occupants are sensed. Departure does not refresh maps; stale entries are retained. Reader key receipt does not refresh its map, nor does Writer action/gesture disclose its primitive to Reader. Inactive Writer cannot sense; after departure its entire dated map stays frozen.

ReadRecord = `{symbol:Note,clock:Clock}`. PossessionReceipt = `{clock:Clock,key:B}`; null initially, successful PassKey records Writer false and Reader true at that Writer-action clock without passive sensing. Feedback = `{clock:Clock,primitive:Primitive,status:ActionStatus,block_reason:BlockReason|null,cost:U,observed_request:Good|null,read_symbol:Note|null,picked_good:Good|null,reward:U}`. Only applied own InspectManifest yields observed_request, only applied own ReadNote yields read_symbol, only applied own Pickup yields picked_good, only applied Deliver yields reward. A wrong Pickup of available Right when H=Left returns Right, never correctness or H. Blocked output optional payloads are null, reward0. Applied implies null block_reason; Blocked implies nonnull reason. History is chronological Feedback array, max4 Writer/max6 Reader; passive receipts and public departure are not fabricated own actions.

View = `{role:Role,writer_program:WriterProgram|null,reader_routine:ReaderRoutine|null,public:PublicSettings,clock:Clock,status:PublicStatus,cell:Cell|null,key:B,cargo:Good|null,credits:U,spent:U,reward:U,known_request:Good|null,belief:[Ratio,Ratio],map:LocalMap,note_read:ReadRecord|null,key_receipt:PossessionReceipt|null,history:[Feedback]}`. Only own program populated for Writer, only own routine for Reader. own credits/rewards/spent come from its original ledger; no peer ledger/private history, Config, arm or researcher state. known_request initially null except Oracle Reader privately receives Config.request at boundary0. Writer paid inspection and Reader paid inspection set exact known_request. Applied nonblank Reader ReadNote sets known_request under supplied truthful encoding and belief point mass; Blank does not change prior/knowledge. Raw false-note witnesses demonstrate mistaken belief; knowledge means controller's decoded target, not researcher-certified truth. Prior [1/2,1/2] changes only under the foregoing permitted sensing/Oracle. Registered Writer programs chosen researcher-side: Retained/Erased ObserveWrite; NoNote ObserveSilent; NoAcquireNoNote Silent. Reader receives none of this selection. Departed Writer history, spent and credits are immutable; reward alone may increase once at Reader settlement. Own Clock/status are public and update at boundaries even when map/history stay stale.

Event = `{kind:EventKind,clock:Clock,actor:Role|null,feedback:Feedback|null,erased:B,terminal_reason:TerminalReason|null}`. Action contains actor and matching feedback, erased false, reason null except Deliver=Delivered. Departure contains null actor/feedback, erased true only Erased, reason null. Settlement null actor/feedback, erased false, reason Delivered/Deadline. Initial no event. Checkpoint = `{clock:Clock,public:PublicStatus,physical:Physical,own:[View,View],event:Event|null}`. Controller choose receives only one View; Checkpoint is researcher-only. Browser Agent projection may expose only selected View plus public topology, labels and visible own dated map; no serialized hidden fields in DOM/export/tooltips/side panes before permitted sensing. Oracle must be visibly labeled privileged. Researcher projection explicitly labels request, arm, field and lineage. Figures/Flump gestures never become controller observations.

## Transactions and supplied routines

Before commit validate primitive, consistent own history/state, role/phase/opportunity, checked arithmetic and counters; mutate a candidate snapshot; charge attempt cost; apply or block; sense own cell; append feedback/event/capture atomically. Insufficient credits is InvalidHistory before mutation. Arithmetic/resource/capture callback failure leaves live transaction state unchanged and returns operational error; no partial Episode pretends success. Bound counters before appending/allocating, including candidate clone capacity.

Wait cost0. Move cost1, legal adjacency; NoKey blocks locked crossing. Writer InspectManifest costs s and Reader costs i; wrong location blocks. PassKey Writer cost1; succeeds at O with active Reader co-located and Writer key, otherwise WrongLocation/NoKey/NoRecipient (precedence location,key,recipient). WriteNote Writer costw, succeeds O else WrongLocation, stores raw symbol and own inspected target lineage; missing paid observation is InvalidHistory. ReadNote Reader costr, succeeds O else WrongLocation, does not refresh map or other observations (including on a block), and returns no lineage. Pickup Reader cost1, succeeds C with empty cargo and available selected good, otherwise WrongLocation/CargoOccupied; unavailable stock is InvalidHistory for this one-cargo world. Deliver Reader cost1, succeeds O with cargo, otherwise WrongLocation/NoCargo. All valid blocks pay costs and consume one role opportunity. Wrong role primitive is InvalidInput. Valid deliveries consume cargo, set settled and terminal, grant [b,12−b] iff cargo==H else [0,0]. Departed Writer original reward entitlement retained. Fixed departure after Writer slot4 atomically removes Writer cell/activity, and only Erased clears note. Failed-handoff witness leaves key_owner Writer and Reader key false.

Writer slots: ObserveWrite=(InspectManifest,Move O,PassKey,WriteNote own observed H); ObserveSilent=(InspectManifest,Move O,PassKey,Wait); Silent=(Wait,Move O,PassKey,Wait). No timing depends on H. Writer spend respectively s+2+w,s+2,2.

BlindGuess=(Move C,Pickup Left,Move O,Deliver); InspectFirst=(Move C,InspectManifest,Pickup own H,Move O,Deliver); Oracle=(Move C,Pickup privileged own H,Move O,Deliver). ReadAdaptive=(ReadNote,Move C, conditional InspectManifest iff Blank and 2*i<g, Pickup decoded/inspected H or Left,Move O,Deliver). Equality guesses Left. Choice checked integer multiplication, no floating arithmetic. All completed routes spend four physical credits; Reader total respectively4,4+i,4,4+r+(Blank and 2*i<g ? i:0). No unused suffix waits are synthesized. Target-sensitive choices are derived from own observation records, never Config.request.

## Outcome, aggregates and order

Costs = `{acquisition:[U,U],writing:[U,U],reading:[U,U],inspection:[U,U],movement:[U,U],handoff:[U,U],pickup:[U,U],delivery:[U,U],wait:[U,U]}`. Each attempted primitive is counted in its role/category, including blocks; Writer inspection is acquisition, Reader inspection inspection; totals equal spent. Counts = `{attempted:[U,U],successful:[U,U],blocked:[U,U],reads:U,nonblank_reads:U,inspections:[U,U],writes:U,key_passes:U}`. Applied Wait counts successful. reads/nonblank_reads/inspections/writes/key_passes count only applied successful corresponding primitives; reads includes Blank, nonblank_reads excludes Blank, inspections includes Writer acquisition and Reader inspection. Generic attempted and Costs retain all blocks. Outcome = `{correct:B,completed:B,deadline:B,terminal_reason:TerminalReason,completion_clock:Clock|null,selected_good:Good|null,belief:[Ratio,Ratio],spent:[U,U],reward:[U,U],net:[I,I],group_net:I,costs:Costs,counts:Counts,note_survived:B}`. Deadline correct/completed false; completion_clock null; retained spending and zero rewards. Delivered completed true, correctness calculated from delivered good; completion_clock action clock; selected_good last successfully picked good (also retained on deadline). note_survived is nonblank immediately after departure, independent of later reading. Net=reward−spent; group_net=sum net. Final belief Reader own belief. All errors lack Outcome, distinct from wrong/deadline.

Episode = `{key:[s,w,r,i,b,arm,routine,request],config:Config,checkpoints:[Checkpoint],outcome:Outcome}`. Arrays ordered nested loops s,w,r,i,b,arm,routine,request in orders above; arms Retained,Erased,NoNote,NoAcquireNoNote; routines BlindGuess,InspectFirst,ReadAdaptive,Oracle; requests Left,Right. Exactly144 strata and4608 keys; requests equally weighted exact1/2.

MeanMetrics = `{correctness:Ratio,completion:Ratio,deadline:Ratio,spent:[Ratio,Ratio],reward:[Ratio,Ratio],net:[Ratio,Ratio],group_net:Ratio,reader_actions:Ratio,nonblank_reads:Ratio,costs:MeanCosts}`. MeanCosts has all nine Costs field names, each [Ratio,Ratio]. Means average these values over both requests, never omit wrong/negative outcomes. MeanRow = `{key:[s,w,r,i,b,arm,routine],metrics:MeanMetrics}`;2304 rows same prefix order.

Contrast labels Retained-Erased,Retained-NoNote,Erased-NoNote,Retained-NoAcquireNoNote in that order. RequestContrast = `{key:[s,w,r,i,b,routine,request,contrast],metrics:MeanMetrics}`; each metric left minus right outcome, including cost deltas, so signed ratios supported. Order stratum,routine,request,contrast (4608). MeanContrast = `{key:[s,w,r,i,b,routine,contrast],metrics:MeanMetrics}` order stratum,routine,contrast (2304). Correctness is Boolean indicator before averaging/differencing, not ratio of successes. Completion/deadline similarly. Envelope = `{key:[s,w,r,i,b,arm],reader_net:Ratio,ties:[ReaderRoutine]}`;576 stratum/arm entries; maximize expected Reader net over BlindGuess,InspectFirst,ReadAdaptive; include all exact ties in routine order, exclude Oracle. This offline arm-specific routine selection is no controller input and no optimality/equilibrium claim.

Evaluation = `{rows:[Episode],means:[MeanRow],request_contrasts:[RequestContrast],contrasts:[MeanContrast],envelopes:[Envelope],counters:Counters}`. CompleteReference = `{protocol_version:U,rows:[Episode],means:[MeanRow],request_contrasts:[RequestContrast],contrasts:[MeanContrast],envelopes:[Envelope],witnesses:[Witness],limits:Limits,counters:Counters,derivation_receipts:[Receipt]}`. version1. Full reference derivation and independent review each have separate120-second/512MiB/256MiB-output caps; archive failures and receipts. No production code/output is input to either role. Independent author and reviewer each implement transitions and Fraction arithmetic, compare every field of every trace/aggregate, not stored success flags/hash alone.

## Witnesses and lifecycle

Witness = `{name:string,config:Config,setup:Physical|null,operations:[WitnessOperation],expected:[Checkpoint],expected_error:ErrorWire|null,invariants:[string]}`. name/invariants ASCII≤128 bytes, operations≤16, expected≤16. Setup null means registered initial state; nonnull researcher setup is privately validated (cohort,credits,custody) and never production input. WitnessOperation = `{kind:string,actor:Role|null,primitive:Primitive|null,note:Note|null}`; kind Act (actor/primitive required), Depart, FinishDeadline, ResetField (only note Blank), CloneReplay (no payload). Actor/primitive/note otherwise null. ResetField is a researcher-only instantaneous witness edit at the existing clock, clearing lineage and leaving own views stale; its expected snapshot has event null and is not an ordinary Episode capture. CloneReplay means clone state, run remaining operations independently, compare every state/view/event/outcome; it has no independent expected capture. Expected arrays contain one post-operation snapshot for Act/Depart/FinishDeadline/ResetField, none for a rejected operation or CloneReplay. ErrorWire = `{kind:string,message:string|null,resource:string|null,limit:U|null}` with kind exactly InvalidInput/InvalidHistory/InvalidReport/ResourceLimit/ArithmeticOverflow/Io; messages≤128 bytes, resource≤32; only ResourceLimit uses resource/limit, other applicable errors use message, ArithmeticOverflow all null. Negative parse/size/overflow tests may be stored as WitnessInput = `{name:string,raw:string,expected_error:ErrorWire,unchanged_sha256:string}` separately in kernel fixture; raw UTF-8≤4096 bytes. Every WitnessInput.unchanged_sha256 binds SHA-256 (no domain prefix) of the canonical initial Checkpoint for Config s=1,w=1,r=1,i=2,b=0,Retained,ReadAdaptive,Left with default Agent-A/Agent-B IDs: `35ce3a486ad1685a1e66be669a3cf90b43972a7d05028b939dda196e0b581e87`. All invalid parse cases use this same pre-mutation context. The preimage is the checkpoint member of ignored `reference-author/invalid-input-starting-state.json`; regenerate it from checkpoints[0] of the sealed row key `[1,1,1,2,0,"Retained","ReadAdaptive","Left"]`, using the canonical codec above. The wrapper file and its metadata are not the hashed preimage. Failed actions leave state hash identical; paid blocked actions are checkpoints, not expected_error.

Register witnesses for both H values in all16 arm/routine combinations; initial views/privileged Oracle; truthful Left/Right writes; raw overwrite then reset; erasure between write/read; retained Writer departure and attempted postdeparture write; fixed public timing; passive key receipt map clock0 vs own key at boundary3; wrong pickup without request leakage; wrong delivery reward0; six Wait Reader deadline; failed handoff with inactive owner and blocked Reader crossings; wrong-location read/inspection/write; blank inspection six-action route; off-grid i=3,g=6 equality GuessLeft; departed original-cohort reward; double delivery; invalid wire/unknown/duplicate/overflow; exact cap and cap-minus-one; clone/replay; opaque ID rename; saved payload/identity/counter/aggregate tampering. Witnesses are separate engineering verification, not added census keys. Failed/negative/zero cases are retained.

## Source and saved report identity

Receipt = `{path:string,bytes:U,sha256:string}`; path is repo-relative ASCII≤192 bytes, no empty/dot/dotdot segment, no backslash/control/quote, sorted lexicographically, unique. Source receipts bind every new persistent_notes production .rs file listed in plan (excluding tests), this protocol, Cargo.toml, Cargo.lock and crates/sugarscape-core/Cargo.toml. Reference receipts bind the three sealed native fixtures. SourceIdentity = `{domain:string,receipts:[Receipt],sha256:string}`; domain persistent-notes-source-v1 or persistent-notes-reference-v1, sha256 over canonical `{domain,receipts}` (exclude sha256). Baseline engines/archived reports retain their own identities and are not relabeled with this new lab identity. Future adapter delivery receipts are separately labeled and never replace native scientific source identity.

Report = `{version:string,protocol_version:U,protocol_id:string,source:SourceIdentity,reference:SourceIdentity,limits:Limits,rows:[Episode],means:[MeanRow],request_contrasts:[RequestContrast],contrasts:[MeanContrast],envelopes:[Envelope],counters:Counters,payload_sha256:string}`. protocol_id persistent-notes-v1; protocol_version1; Report.version persistent-notes-diagnostic-v1. payload digest SHA256 of canonical Report excluding payload_sha256. No wall time, PID, path, timestamp, machine memory measurement or random ID enters deterministic payload. OperationalReceipt = `{kind:string,elapsed_milliseconds:U,peak_rss_bytes:U,report_bytes:U,report_sha256:string,source_sha256:string,reference_sha256:string,error:ErrorWire|null}` is external first/repeat/engineering receipt, never hashed into Report. Error receipt report_sha256 empty only when no complete report exists. Summary = `{version:string,protocol_version:U,protocol_id:string,source:SourceIdentity,reference:SourceIdentity,report_sha256:string,means:[MeanRow],request_contrasts:[RequestContrast],contrasts:[MeanContrast],envelopes:[Envelope],counters:Counters}`; Summary.version persistent-notes-summary-v1; summary contains all aggregates, no sampled substitute.

Validation reconstructs all Config keys, state transitions, own views/clocks, outcome arithmetic, costs/counts, each mean/contrast/envelope and counters from rows; checks exact registered source/reference and fresh embedded receipts, full reference agreement and payload hash. Fresh report success flags are never trusted. Duplicate, omitted, reordered or extra rows fail. Saving/summary validation replays saved rows with no production collector invocation. Write/flush failures are operational and no unavailable report may be advertised successful. Report/source canonical hashes are distinct from raw complete-reference receipts.
