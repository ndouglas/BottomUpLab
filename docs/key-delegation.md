# Key delegation: complete measured schedule census

This original bounded construction asks when handing over an access tool permits useful assistance and when doing so serves the Giver's private payoff. The [registered protocol](superpowers/protocols/2026-10-12-key-delegation.md) fixes its physical rules, information, finite schedules, exhaustive calculation and caps. [KEY-1–3](reproducibility.md#key-1) distinguish physical correctness, bounded private incentives and coordination. These are working scientific findings within that registration.

## Primary-source scope

[Miller, Donnelley and Karp (2007), *Delegating Responsibility in Digital Systems: Horton's “Who Done It?”*](https://www.usenix.org/legacy/event/hotsec07/tech/full_papers/miller/miller_html/index.html) describes delegated object authority with identity-based responsibility tracking. Our unique physical key is a bounded analogy for access delegation; it does not reproduce Horton's object-reference semantics, cryptography, attribution protocol or revocation. [Khetarpal et al. (2020), *What can I do here? A Theory of Affordances in Reinforcement Learning*](https://proceedings.mlr.press/v119/khetarpal20a.html) studies state-dependent action feasibility for planning and transition-model learning. Here feasibility is supplied; that learning algorithm is not implemented. Both primary pages were verified on October 14, 2026. These conceptual anchors supply no novelty claim.

## Model and prior predictions

Two Agents share Staging P–Outside O–Cache C. The Receiver starts O; the Giver starts O at handoff distance d=0 and P at d=1. A token starts C and is delivered O. P–O is freely traversable. Each O–C crossing requires the moving Agent's own key; a pass never opens a global gate. Exactly one Agent owns the unique key, initially the Giver in the main census. There is no copying, dropping, theft, return or postterminal phase.

Six rounds execute Giver then Receiver, with 32 credits each. Wait is free; Approach and Receiver Advance each cost one, even when blocked. Pass costs t even when blocked and succeeds only with permission e, Giver possession and co-location. Only the sender pays. Advance executes one primitive: outbound Move, Pickup, return Move or Deliver. Delivery pays b to the Giver and 12−b to the Receiver once, ends execution and leaves suffixes uncharged. Deadline non-delivery pays zero reward and retains actual costs. Opaque Agent names do not change role order.

Execution receives only own word/state/feedback/committed local history and public clock/termination. Successful Pass gives both participants a timestamped own-possession receipt; the passive Receiver's map remains dated to actual sensing. Failed Pass gives no Receiver receipt. The team benchmark uses identical initial information and execution interfaces.

The approved design's prospective algebraic predictions were: disabled transfer prevents main-census delivery; enabled SuppliedHandoff delivers in round 4+d with spending (t+d,4), private nets (b−t−d,8−b) and group net 8−t−d; all-Wait remains pure; supplied minimal handoff is pure when b≥t+d in this grid; changing b at fixed words preserves physics/spending/group net. These predictions preceded collection. The observations below come from the independently accepted measurements rather than assumed outcomes.
