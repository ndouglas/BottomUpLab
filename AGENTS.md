# Research guidance

For paper/model reproduction, scientific interpretation and research write-ups, read [docs/research-method.md](docs/research-method.md) before proceeding.

- Follow faithful reproduction, transparent charitable reconstruction where necessary, then scientific evaluation of responses, follow-ups, critiques and counterfactuals. Evaluating scientific value is the highest purpose.
- Distinguish reproducing code or a phenomenon from supporting the paper's mechanism, equilibrium claims or broader generality. A faithfully simulated learning failure is not automatically an implementation bug.
- Justify charitable readings from sources; keep every variant labeled and preserve the original. Never choose an interpretation merely because it fits the desired outcome.
- Evaluate claims individually, retaining successful results, uncertainties, censored data and competing explanations. Use the paper catalog and stable reproducibility-register entries.
- Check existing literature before claiming novelty. Keep working notes distinct from publication-ready findings and honor the current user-approved experimental and publication scope.

These research instructions supplement the applicable development guidelines; they do not authorize new scientific execution or replace explicit user instructions.
